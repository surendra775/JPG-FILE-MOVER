\# File Mover



A Python project that moves files from one location to another.



\## Features



\* Moves files between folders.

\* Uses Python's `shutil` module.

\* Uses file paths to specify source and destination locations.



\## Technologies Used



\* Python

\* os module

\* shutil module



\## Purpose



This project helps me practice Python file handling, working with file paths, and moving files between folders.
